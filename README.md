# Kit de reconstruction — Les Canonniers

Ce dossier regroupe le matériel utile pour refaire une version web/mobile du jeu **Les Canonniers** à partir d'un exemplaire physique documenté dans cette conversation et d'un scan PDF des règles.[file:42][file:34][file:35][file:36][file:37][file:40][file:41]

## Contenu

- `assets/user-files/` : copies du PDF des règles et des photos fournies.[file:42]
- `docs/regles-reference.md` : transcription/synthèse structurée des règles pour consultation rapide.[file:42]
- `docs/inventaire-materiel.md` : inventaire visuel et quantitatif du matériel observé.[file:35][file:40][file:41]
- `docs/spec-dev.md` : base de spécification fonctionnelle pour refaire le jeu en webapp.[file:42][file:40][file:41]
- `docs/prompt-claude-code.md` : prompt complet à fournir à Claude Code pour qu'il reconstruise le projet.[file:42][file:40][file:41]

## Matériel observé dans la boîte

Le matériel photographié comprend la boîte illustrée, le plateau métallique bicolore vert et blanc, le ballon aimanté, un dé, les paquets de cartes et le livret de règles.[file:35][file:36][file:37]

## Deck observé

L'exemplaire documenté contient 109 cartes au total, dont 108 cartes jouables nommées et 1 carte vierge.[file:42]
